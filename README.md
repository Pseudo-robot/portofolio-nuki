# WebGIS Pelabuhan Indonesia

WebGIS sederhana menampilkan sebaran Pelabuhan Umum di Indonesia.

## Teknologi
- Leaflet.js
- OpenStreetMap
- WMS GeoServer Kementerian Perhubungan

## Sumber Data
Kementerian Perhubungan RI  
Layer: PELABUHAN_PT_NEW (WMS)
