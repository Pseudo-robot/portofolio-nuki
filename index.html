Interactive geospatial applications for public data visualization

Project Overview

This project demonstrates a simple yet production-ready WebGIS application that visualizes the distribution of public ports in Indonesia using official government geospatial services.

Key Features

  • Interactive web map with OpenStreetMap basemap
  • Government WMS layer from Ministry of Transportation
  • Click-based feature information (GetFeatureInfo)
  • Official legend sourced directly from GeoServer
  • Fully static deployment via GitHub Pages

Technical Stack

Frontend HTML, CSS, JavaScript, Leaflet.js
Geospatial Service WMS (OGC Standard)
Data Source Ministry of Transportation (Indonesia)
Deployment GitHub Pages (Static Hosting)
